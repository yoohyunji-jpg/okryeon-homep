오픈 · 마감 가이드

센터 오픈과 마감 시 확인해야 할 순서와 방법입니다.

OPEN

센터 오픈

수업 시작 전 공간을 세팅합니다. 조명 → 음악 → 향 순서로 진행하세요.

1
조명
센터 전체 조명 점등
입장 후 전체 조명을 켜주세요. 공간이 밝아야 음악·향 세팅이 순조롭게 진행됩니다.
가장 먼저 전체 점등
2
음악 세팅
아이패드 → Apple Music → 블루투스 스피커
센터에 비치된 아이패드의 Apple Music에 재생목록이 세팅되어 있습니다.
그대로 플레이하면 됩니다.
블루투스 연결 방법
  • 스피커 위치 — 정수기 옆 블루투스 스피커
  • 블루투스 이름 — hyunji'20
  • 아이패드에서 설정 → 블루투스에서 hyunji'20을 찾아 연결하세요
  • 이미 연결되어 있다면 바로 재생하면 됩니다
🔊 볼륨은 너무 크지 않게, 적적한 느낌만 없는 정도로 설정하세요. 수업 중 대화가 편안하게 들리는 수준이면 적당합니다.
hyunji'20 Apple Music 재생목록 그대로 낮은 볼륨 유지
3
향 세팅
티라이트 + 디퓨저 아로마 오일
공간에 향을 더해 센터 분위기를 완성합니다.
티라이트 점화와 디퓨저 오일 투입 두 가지를 모두 진행하세요.
세팅 방법
  • 티라이트 — 라이터로 불을 붙여 지정된 위치에 놓으세요
  • 디퓨저 아로마 오일 — 센터에 비치된 오일을 5~6방울 디퓨저에 떨어뜨려 주세요
티라이트 점화 아로마 오일 5~6방울
✓
오픈 체크리스트
완료한 항목을 탭하여 체크하세요
전체 조명 점등 완료
아이패드 Apple Music 재생 확인
블루투스 스피커(hyunji'20) 연결 확인
볼륨 적정 수준 확인
티라이트 점화 완료
디퓨저 아로마 오일 5~6방울 투입 완료

센터 마감

마지막 수업 후 공간을 정리하고 보안을 설정합니다.

1
공간 정돈
로봇 청소기 가동 전 바닥 정리
예약 시간에 맞춰 로봇 청소기가 자동으로 가동됩니다.
바닥에 장애물이 없도록 미리 정리해 주세요.
확인 사항
  • 소도구 — 폼롤러, 밴드, 볼 등 바닥에 놓인 소도구 모두 제자리에 수납
  • 매트 — 바닥에 펼쳐진 매트 모두 말거나 수납
  • 기구 주변 바닥까지 확인하세요
로봇 청소기 가동 전 필수 소도구 수납 매트 정리
2
소등
전체 조명 소등
공간 정돈 후 전체 조명을 끄세요.
티라이트 불씨도 반드시 확인하고 끄세요.
전체 소등 티라이트 불씨 확인
3
경계 모드 설정
저녁 마감 강사만 해당
저녁 마지막 강사님만 경계 모드를 설정하고 퇴장하세요.
낮 시간대 강사님은 해당 없습니다.
⚠️ 경계 모드는 마지막으로 퇴장하는 저녁 강사님만 설정합니다. 중간 강사님이 설정하지 않도록 주의하세요.
저녁 마감 강사 전용 퇴장 직전 설정
✓
마감 체크리스트
완료한 항목을 탭하여 체크하세요
바닥 소도구 전부 수납 완료
매트 정리 완료
티라이트 불씨 소화 확인
전체 소등 완료
경계 모드 설정 완료 (저녁 마감 강사)
